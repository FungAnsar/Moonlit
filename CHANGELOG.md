# Moonlit Version History

Moonlit was released before this GitHub repository was created. This file
preserves the published update history for earlier releases. GitHub Releases
are used for release notes from the first release tracked in this repository
forward.

Moonlit is distributed through the Apple App Store. GitHub Releases do not
include application installers.

## Current Version

### 1.5 — 2026-08-08

- Improved several layout issues and fixed incorrect pinyin display.
- Fixed issues when accessing shared pages after sharing content.

## Earlier Releases

### 1.4 — 2026-07-12

- Added a new Classics category, including Tao Te Ching, Zhuangzi, Diamond Sutra, Caigentan, and more.
- Refined typography, layout styles, and the reading and listening experience.

### 1.3 — 2026-06-26

- Expanded free content to 10 articles under each topic.
- Improved the text-to-speech listening experience.
- Added content update history for easier tracking of changes.

### 1.2 — 2026-06-23

- Improved reading layout.
- Added browsing by author.
- Improved voice playback.

### 1.1 — 2026-06-14

- Initial post-launch update.

### 1.0 — 2026-05-23

- Initial release.
